# Casos de uso y guía de usuario final

Esta guía resume los flujos principales de EduLinker para dirección, maestros,
vocales y familias, así como los pasos básicos de configuración.

## Configuración inicial (administradores/directores)

1. Crear la escuela y habilitar el tenant correspondiente.
2. Registrar usuarios directivos y maestros con el rol correcto.
3. Crear el ciclo escolar actual y marcarlo como vigente.
4. Crear grupos y asignar titulares e itinerantes.
5. Vincular alumnos con sus padres y grupos.
6. Revisar permisos en `permissions.md` y comunicar las responsabilidades.

## Dirección

### Anuncios y eventos
1. Crear anuncios globales o por grupo desde el panel web.
2. Programar eventos y adjuntar documentos o fotos.
3. Enviar notificaciones a toda la comunidad o a grupos específicos.

### Analítica y seguimiento
1. Acceder a Analíticas para revisar KPIs de quejas, recaudaciones y encuestas.
2. Consultar la asistencia a eventos y la tasa de participación por grupo.
3. Exportar reportes o compartir métricas clave con el equipo directivo.

## Maestros

### Tareas y comunicados
1. Publicar tareas con descripción, fecha de entrega y adjuntos.
2. Enviar anuncios al grupo asignado para recordatorios o avisos rápidos.

### Quejas y sugerencias
1. Revisar nuevas quejas o sugerencias recibidas desde familias.
2. Responder dentro del hilo para mantener el historial.
3. Escalar o cerrar el caso según el protocolo del plantel.

## Vocales

### Recaudaciones y evidencias
1. Crear eventos de recaudación y registrar aportaciones por grupo.
2. Subir evidencias de gastos con documentos o fotos.
3. Compartir el balance con la dirección y con las familias.

## Familias (padres/madres/tutores)

### Quejas y sugerencias
1. Seleccionar el grupo y maestro destinatario.
2. Redactar una queja o sugerencia y enviarla.
3. Seguir el hilo de respuestas y recibir notificaciones.

### Encuestas y recaudaciones
1. Responder encuestas abiertas desde web o móvil.
2. Consultar campañas de recaudación y subir evidencia de aportaciones.

### Calendario y RSVP
1. Copiar el enlace del calendario desde Perfil.
2. Suscribirse en Google Calendar, Outlook o Apple Calendar.
3. Confirmar asistencia a eventos (RSVP) desde el módulo de eventos.

## Flujo de encuestas

1. Dirección o maestro crea la encuesta con rango de fechas y opciones.
2. Las familias reciben notificación y votan.
3. El sistema calcula participación por grupo para analítica.

## Flujo de eventos y RSVP

1. Dirección o maestro crea un evento.
2. Familias confirman asistencia (Sí, Tal vez, No).
3. Analítica de asistencia consolida RSVP y tasa de participación por grupo.

## Uso del calendario y regeneración de token

1. Desde Perfil, copiar el `ics_token` y el enlace de suscripción.
2. Pegar el enlace en el cliente de calendario preferido.
3. Si el enlace se comparte accidentalmente, usar “Regenerar token” en Perfil.
4. El token anterior queda invalidado y se entrega un nuevo enlace seguro.

## Notificaciones

- Dirección y maestros reciben alertas de nuevas quejas/sugerencias.
- Familias reciben avisos de eventos, tareas y respuestas en hilos.

Para más detalles sobre la matriz de roles y permisos consulte `permissions.md`.
