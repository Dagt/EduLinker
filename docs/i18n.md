# Internacionalización (i18n)

EduLinker usa archivos de traducción en web y móvil para centralizar las cadenas.

## Web (Next.js)

Las traducciones viven en `web/src/i18n/{lang}.json`.

Ejemplo:

```json
{
  "UploadButton": {
    "presignError": "Presign error",
    "fileLabel": "Upload file"
  }
}
```

Uso en componentes:

```tsx
import { useTranslations } from "next-intl";

const t = useTranslations("UploadButton");
return <button aria-label={t("fileLabel")}>{t("presignError")}</button>;
```

## Mobile (React Native / Expo)

Las traducciones se mantienen en `mobile/src/i18n.ts`.

Ejemplo:

```ts
const translations = {
  en: { uploads: { takePhoto: "Take photo" } },
  es: { uploads: { takePhoto: "Tomar foto" } },
};
```

Uso en componentes:

```tsx
import i18n from "../i18n";

<Button title={i18n.t("uploads.takePhoto")} onPress={takePhoto} />
```
